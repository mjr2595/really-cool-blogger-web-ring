# Really cool blogger web ring

A really cool webring for really cool bloggers

https://webring.jacobasper.com/

## add yourself

Make a PR and add your name and site URL to the `webring.json`

## add to your site

It's ultimately up to you how you add yourself to the webring, but here's an example to get ya going!

If you set your id to `20jasper`, then the previous path would be `/prev/20jasper`

```html
<nav>
  <a href="https://webring.jacobasper.com/prev/<id>">previous</a>
  <a href="https://webring.jacobasper.com/">Really Cool Blogger Web Ring</a>
  <a href="https://webring.jacobasper.com/next/<id>">next</a>
</nav>
```
